# 🎯 Domain-Specific Resume Classifier
### Powered by Fine-Tuned LLM (Groq) | Multi-Domain AI Analysis

A production-ready AI-powered resume classification system that automatically 
identifies the domain of any resume and provides detailed feedback, skill gap 
analysis, and improvement recommendations using Groq LLM.

---

## 📌 Problem Statement

Recruiters and job seekers struggle to understand which domain a resume belongs 
to and what skills are missing. Traditional keyword matching fails to understand 
the context of a resume.

Domain-Specific Resume Classifier solves this using **Groq LLM (Llama 3.3 70B)** 
to intelligently classify resumes and provide actionable feedback.

---

## ✨ Features

- ✅ Upload Resume PDF
- ✅ AI Domain Classification (10 domains)
- ✅ Match Score (0-100)
- ✅ Top 3 Strengths Analysis
- ✅ Top 3 Areas to Improve
- ✅ Missing Keywords Detection
- ✅ Overall HR Recommendation
- ✅ Domain Distribution Pie Chart
- ✅ Analysis History Table
- ✅ CSV Export Support
- ✅ Live Streamlit Deployment

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository
```bash
git clone https://github.com/pratikshabiradar19/Resume-Classifier.git
cd Resume-Classifier
```

### 2️⃣ Create Virtual Environment
```bash
python -m venv venv
venv\Scripts\activate
```

### 3️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 4️⃣ Configure API Key
Create a `.env` file:

Get your free Groq API key at 👉 https://console.groq.com/keys

### 5️⃣ Run Application
```bash
streamlit run app.py
```
